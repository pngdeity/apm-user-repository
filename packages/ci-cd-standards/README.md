# ci-cd-standards

CI/CD pipeline design standards and architectural patterns.

## Primitives

### Instructions

- **GitHub Actions Standards** — Runtime security, performance optimization, workflow architecture, and validation mandates
- **CNCF Buildpacks** — Future architecture reference for migrating from imperative CI/CD to declarative Cloud Native Buildpacks

### Skills

- **Inversion of Control CI/CD** — Architectural pattern for decoupling pipeline logic from vendor-specific CI platforms via shell script extraction
