# Architecture decision records and technical design documents

## ADR Schema (Hybrid Nygard/MADR)

Every ADR must include these sections:
- Metadata: Title, Date, Status (Proposed/Accepted/Deprecated)
- Context and Problem Statement: Description of the challenge
- Decision Drivers: What forces are at play?
- Architecture Decision: The chosen path
- Alternatives Considered: **(Mandatory)** List and brief analysis
- Consequences: Positive and negative impacts

## TDD Schema (Micro-Leaf Design)

Every TDD must include these sections:
- Metadata: Objective and Non-Goals
- Interface Contract: Strict input/output type definitions
- Execution Logic: Step-by-step processing
- Failure Modes and Resilience: Explicit error handling
- Testing Strategy: Unit and integration plans
