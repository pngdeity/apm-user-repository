# pngdeity Defaults

This is a meta-package. The following standards are included transitively:

- **development-practices** — git standards, engineering workflow, code style conventions
- **ci-cd-standards** — CI/CD pipeline design, GitHub Actions best practices, IoC architecture
- **code-review-commons** — code review guidelines and critical constraints
